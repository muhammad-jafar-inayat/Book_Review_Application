# 📚 Book Review Application

This is a Node.js-based Book Review Application that allows users to explore and review books using various endpoints and functionalities. The project carries **30 points** toward the final grade and is divided into General User tasks, Registered User tasks, and Node.js method implementations.

---

## 🚀 Features

### 🔹 General Users

| Task No. | Description                                           | Points |
|----------|-------------------------------------------------------|--------|
| 1        | Get the book list available in the shop               | 2      |
| 2        | Get the books based on ISBN                           | 2      |
| 3        | Get all books by Author                               | 2      |
| 4        | Get all books based on Title                          | 2      |
| 5        | Get book Review                                       | 2      |
| 6        | Register New user                                     | 3      |
| 7        | Login as a Registered user                            | 3      |

### 🔹 Registered Users

| Task No. | Description                                           | Points |
|----------|-------------------------------------------------------|--------|
| 8        | Add/Modify a book review                              | 2      |
| 9        | Delete book review added by that particular user      | 2      |
